# 3m-ui

轻量级 Mihomo 核心管理面板。

## 功能

- Mihomo 核心管理
- 节点管理
- 配置管理
- Listener 管理
- 节点 URI 导出
- 订阅与配置分发
- 流量与运行状态查看
- Web 管理界面

3m-ui 不依赖 Sub-Converter。节点 URI 由 3m-ui 原生生成，支持直接导出和分享。
